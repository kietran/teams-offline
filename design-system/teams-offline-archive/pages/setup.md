This page overrides the generated Master where rules conflict.

- Pattern: three-step desktop setup: `Kết nối Chrome`, `Chọn kênh`, `Nơi lưu`.
- Colors: `#F8FAFC` canvas, white surface, slate text, cool-gray dividers,
  `#2563EB` primary, `#15803D` success.
- Typography: system UI / Segoe UI / Noto Sans; no remote font.
- Layout: 280px progress rail plus flexible content surface.
- Channel selection: one instruction panel, one primary `Thêm kênh đang mở`
  action, and an open selected-channel list with dividers.
- Controls: 44px minimum height, visible focus, text labels on every action.
- Motion: 150–200ms state transitions only; respect reduced motion.
- Forbidden: Microsoft OAuth/Graph/admin copy, path field, marketing hero,
  dashboard, decorative card grid, gradients, large shadows, or old Windows UI.
